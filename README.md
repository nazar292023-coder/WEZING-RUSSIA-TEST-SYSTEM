# WEZING RUSSIA | TEST SYSTEM

Готовый Telegram-бот на Python 3.12, Flask и python-telegram-bot 21.10.

## Возможности
- подтверждение назначения скриншотом;
- тесты ЛД организаций и администрации;
- настройка количества вопросов, времени и проходного балла через переменные окружения;
- подготовка из 5 тренировочных вопросов и запуск основного теста через заданную паузу;
- cooldown после провала (по конкретному направлению и организации);
- заявки на медиа: игровой ник, TikTok-профиль, подписчики, средние просмотры и обязательная ссылка на TikTok-видео о WEZING RUSSIA;
- ручное решение администрации по медиа-заявке;
- редактируемая база знаний для ответов по проекту;
- простой каталог товаров и заявки на заказ;
- `/admin` со статистикой и базовыми настройками;
- HTTP-проверка `/` для Render.

## Настройка Render
1. Создайте Web Service из этого репозитория или загрузите файлы в GitHub.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `python main.py`
4. В Environment добавьте:
   - `BOT_TOKEN` — токен Telegram-бота из BotFather;
   - `ADMIN_ID` — ваш числовой Telegram ID.
5. После Deploy откройте URL сервиса: должен появиться `WEZING RUSSIA TEST SYSTEM: OK`.

## Переменные окружения
- `QUESTION_COUNT` — вопросов в тесте (по умолчанию 20)
- `TEST_SECONDS` — длительность теста в секундах (300)
- `PASS_SCORE` — проходной балл (13)
- `PREP_MINUTES` — пауза между подготовкой и настоящим тестом (5)
- `COOLDOWN_HOURS` — блокировка после провала (72)
- `MEDIA_MIN_VIEWS` — минимум средних просмотров (300)
- `MEDIA_MIN_FOLLOWERS` — минимум подписчиков (30)
- `DB_PATH` — путь к SQLite базе

## Важно
- Ссылка на видео TikTok проверяется по формату, а содержание и реальная статистика проверяются администрацией вручную. Бот не может надёжно подтвердить просмотры/подписчиков только по введённым числам.
- База SQLite на бесплатном Render может сбрасываться при пересоздании/перезапуске инстанса. Для постоянного хранения данных используйте подключённый persistent disk или внешнюю базу данных.
- Бот использует polling, поэтому запускайте только один экземпляр сервиса.
- Встроенная помощь — это поиск по базе знаний, а не генеративный ИИ. Администратор добавляет ответы через `/admin` в формате `вопрос | ответ`.
- Каталог товаров создаёт заявки, но не принимает оплату автоматически.
- Тестовые вопросы являются шаблонными. Перед запуском на проекте замените их на утверждённые правила WEZING RUSSIA.
